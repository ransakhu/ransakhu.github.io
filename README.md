# Rand — Design & Engineering Portfolio

A personal portfolio presenting selected work across research, product design, SwiftUI development, and machine learning.

## Featured work

- **ezibda** — a macOS photo-library app with on-device semantic search.
- **Papricka** — an iOS sourdough-starter tracker.
- **Ratabah** — a bilingual focus and task app.
- **Abyan** — an investment-app UX case study.

The page includes project context, roles, technology summaries, and links to App Store listings or case studies, followed by approach, about, and contact sections.

## Built with

HTML, CSS, and vanilla JavaScript. The site uses a single HTML file with embedded project images and Google Fonts. No framework or build step is required.

## Getting started

1. Clone this repository.
2. Open `index.html` in a browser, or serve it locally:

   ```sh
   python3 -m http.server 8000
   ```

3. Visit `http://localhost:8000`.

## Project structure

- `index.html` — page content, styles, embedded images, and interactions.
- `README.md` — repository overview.

## Editing

Update project copy, links, and visuals in `index.html`. Styles are in the `<style>` block; the script at the end handles scroll-based highlights and reveal animations. Google Fonts requires an internet connection.
